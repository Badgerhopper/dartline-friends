# DartLine Friends Edition

Personal-use darts app extension of [InstaDarts](https://github.com/Instadarts/instadarts), providing on-device camera scoring and online matches.

This repository contains original DartLine modifications over a pinned upstream version of InstaDarts. See DARTLINE_NOTICE.md for license information. The Docker build fetches and builds upstream source and runs tests before deployment.

**Status:** Installation and real-world camera accuracy not yet validated on an iPhone. Source code AGPL-3.0-only.
